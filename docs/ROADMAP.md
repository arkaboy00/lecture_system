# План разработки (на 15.10.2026)

Система в одном репозитории `lecture_system` (до 16.10.2026 были два, `lecture_capture` и `lecture_desktop`, история сохранена):
- **`android/`**: Android-приложение, записывает лекцию (звук, фото, журнал событий).
- **`desktop/`**: ноутбук. Забирает лекции по Wi-Fi, распознаёт речь, готовит материалы для конспекта. Конспект в Obsidian пишет Claude Code скиллом `/konspekt`.

Документы:
- `SPEC.md`: требования и формат папки лекции;
- `IDEAS.md`: идеи пользователя с предложениями по реализации;
- этот файл: что сделано и в каком порядке делать дальше.

Каждый этап начинается с плана и идёт только после «ок».

## Дальше, по порядку

### Этап 5. Приёмка на Samsung S10e (вручную, пользователь)

Чек-лист в `SPEC.md` §9:
- настройки батареи One UI;
- 20 минут записи с заблокированным экраном;
- звонок: должно появиться `audio_silenced`;
- восстановление после принудительной остановки;
- 12 Мп у фото и логическая камера 0.5x;
- «Мои файлы» открывают папку лекции.

APK передаётся по локальной сети (кабеля к S10e нет).

### Этап 9. Фото: поворот и обрезка (IDEAS 6, 7)

- **Переключатель поворота на экране камеры** (авто / книжная / альбомная) с индикатором и записью в EXIF. Причина: фото 22 лекции 15.10 сохранилось боком.
- **Неразрушающая обрезка**: событие `crop` с `rect`, позже `quad` для исправления перспективы. Задаётся в крупном просмотре кадра. Обрезанную копию делает ноутбук.
- **Ноутбук**: применять `crop` после поворота по EXIF, отдавать модели обрезанную копию.

### Этап 10. Чёткость текста на фото (IDEAS 8, исследование)

1. Сначала дешёвые варианты: `MINIMIZE_LATENCY`, затем Camera2 interop `NOISE_REDUCTION_MODE` и `EDGE_MODE`.
2. Если не хватит: кадр из `ImageAnalysis`.
3. Сравнить на распечатанном листе: число (дисперсия лапласиана) и качество распознавания текста. Провести на обоих телефонах.
4. Решение пользователя: чёткий текст важнее отсутствия шума.

### Этап 11. Альбомная ориентация (IDEAS 4)

- Адаптивные раскладки главного экрана, каталога и просмотра.
- Состояние переживает поворот.
- Тест: поворот экрана во время записи.

### Ноутбук: улучшения обработки (без отдельных этапов, по мере лекций)

- **Слайды**:
  - сопоставлять отдельные фото типа «слайд» со страницами сборника;
  - искать разделы начиная со страницы, где закончилась прошлая лекция (сейчас выбор разделов приблизительный: для лекции 15.10 лишним попал раздел «ХТО»).
- **Подсказки распознаванию по времени**: свои термины для каждого сегмента (по фото, снятым рядом).
- **Настройка распознавания на новых лекциях**:
  - пороги «(?)»;
  - глоссарии предметов (скилл предлагает новые термины);
  - сравнение по сумме терминов, потому что прогоны Whisper немного различаются.
- **Части лекции**: сейчас каждая часть получает свой конспект со ссылками «Начало / Продолжение». Если захочется один общий конспект, склеивать части по `part` и названию.
- **Автоматизация конспекта** (`claude -p` после «Обработать»): по желанию, когда формат конспекта устоится.
