# Lecture System

Записывает лекции на телефон и превращает их в конспекты в Obsidian.

```
телефон (android/)                   ноутбук (desktop/)                       хранилище Obsidian
звук, фото доски / тетради /  ─Wi-Fi─▶ синхронизация → распознавание     ─────▶ конспекты пишет
слайдов, заметки, отметки              речи (GPU) → материалы для конспекта     Claude Code
«важно»                                (текст + фото + слайды курса)            (скилл /konspekt)
```

Интерфейс приложения и конспекты на русском. Код, комментарии и коммиты на английском.

Автор: [arkaboy00](https://github.com/arkaboy00)

## Части

| Папка | Что это | На чём |
|---|---|---|
| [`android/`](android/README.ru.md) | Lecture Capture, приложение для телефона. Записывает «черновик лекции» в папку с журналом событий, который только дописывается | Kotlin, Jetpack Compose, CameraX |
| [`desktop/`](desktop/README.ru.md) | Ноутбук: синхронизация с телефоном по Wi-Fi, распознавание речи, материалы для конспекта, хранилище Obsidian, скилл Claude Code | Python 3.14, faster-whisper, PyMuPDF, tkinter |
| [`docs/`](docs) | [SPEC.md](docs/SPEC.md): требования и формат папки лекции (договор между частями); [IDEAS.md](docs/IDEAS.md): идеи и предложения; [ROADMAP.md](docs/ROADMAP.md): что сделано и что дальше | на русском |

## Как проходит лекция

1. **Телефон.** Начать лекцию (предмет, название), записывать звук, фотографировать доску, тетрадь и слайды. Важные моменты отмечать звездой, при необходимости набирать заметки. «Сохранить и выйти» завершает лекцию, после перерыва её продолжает кнопка «Часть 2».
2. **Ноутбук, дома.** Значок «Лекции» на рабочем столе → «Синхронизировать». На телефоне в это время «Синхр.» → «Начать синхронизацию». Затем «Обработать»: распознавание речи на видеокарте, около 15 минут на два часа звука.
3. **Конспект.** В Claude Code: `/konspekt` (или «конспект по последней лекции»). Скилл:
   - читает фото;
   - заново распознаёт речь с терминами этой лекции;
   - пишет конспект в хранилище `~/Documents/Конспекты`;
   - собирает в `<предмет>/Контроль/`, что повторить к рубежным контролям и экзамену.

## Принципы

- Сырые данные не правятся: телефон только дописывает события, ноутбук пишет в свою рабочую папку.
- Потерять речь лектора хуже, чем оставить шум: сомнительные куски сохраняются с пометкой.
- Ничего не работает в фоне: служба синхронизации и окно на ноутбуке запускаются по требованию и сами завершаются.
- Каждый этап начинается с плана и идёт только после «ок» автора.
